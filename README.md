# Python 全栈学习路线

> 适用人群：前端工程师转 Python 全栈
> 总时长：12 周 | 每日建议：1-2 小时

## 目录结构

```
python-course/
├── 01-basics/           # 第 1-2 周：Python 基础
│   ├── week1-syntax/    #   语法速通
│   ├── week2-essentials/#   基础巩固
│   └── project-cli-todo/#   CLI Todo List 项目
├── 02-oop-pythonic/     # 第 3-4 周：面向对象与 Pythonic
│   ├── week3-oop/       #   面向对象
│   ├── week4-pythonic/  #   Pythonic 编程
│   └── project-todo-class/#  Todo class 重构项目
├── 03-advanced/         # 第 5-6 周：进阶 Python
│   ├── week5-advanced/  #   高级特性
│   ├── week6-async/     #   异步编程
│   └── project-async-downloader/ # 异步下载器
├── 04-fastapi/          # 第 7-8 周：FastAPI Web 框架
│   ├── week7-basics/    #   FastAPI 基础
│   ├── week8-advanced/  #   FastAPI 进阶
│   └── project-todo-api/#   Todo API 项目
├── 05-database/         # 第 9-10 周：数据库
│   ├── week9-sql/       #   SQL + SQLAlchemy
│   ├── week10-fastapi-db/#   FastAPI + 数据库
│   └── project-todo-db/ #   Todo 数据库项目
└── 06-fullstack/        # 第 11-12 周：全栈
    ├── week11-auth/     #   用户认证
    ├── week12-deploy/   #   部署
    └── project-graduation/ # 毕业项目
```

## 学习路线

| 阶段 | 周次 | 内容 | 难度 |
|------|------|------|------|
| 第一阶段 | 1-2 | Python 基础语法 + 基础巩固 | ★☆☆☆☆ |
| 第二阶段 | 3-4 | 面向对象 + Pythonic 编程 | ★★☆☆☆ |
| 第三阶段 | 5-6 | 高级特性 + 异步编程 | ★★★☆☆ |
| 第四阶段 | 7-8 | FastAPI Web 框架 | ★★★☆☆ |
| 第五阶段 | 9-10 | 数据库 + FastAPI 整合 | ★★★★☆ |
| 第六阶段 | 11-12 | 认证 + 部署 + 全栈项目 | ★★★★☆ |

## 每个目录内容

每个阶段目录包含：
- `README.md` — 详细每日计划 + 代码示例
- `code/` — 当日练习代码（如有）
- `project/` — 周项目（如该周有）

## 前置知识

- HTML / CSS / JavaScript 基础（前端工程师已有）
- 命令行基本操作（cd, ls, mkdir）
- Git 基础

## 推荐工具

- **编辑器**：VS Code + Python 插件
- **终端**：iTerm2（macOS）/ 系统终端
- **Python 版本管理**：pyenv
- **API 测试**：curl / Postman / FastAPI 自带 /docs
